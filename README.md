<h1>Instruções de execução</h1>

<hr>

<h3>Após clonar o projeto, abra-o no terminal e siga a lista de instruções abaixo:</h3>

Execute o comando `composer update`; <br>
Execute o comando `npm install`; <br>
Duplique, cole e copie ou renomeie o arquivo .env.example para .env; <br>
Execute o comando `php artisan key:generate`. <br>

*Obs: as alterações necessárias dentro do arquivo .env já estão presentes no .env.example.

<h3>Por fim, mantenha abertas duas abas/janelas do terminal, e execute, em cada uma, os seguintes comandos:</h3>

`php artisan serve`; <br>
`npm run dev`. <br>
